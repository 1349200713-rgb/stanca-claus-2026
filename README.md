# Santa Ops 2026 每日经营驾驶舱

经营、广告、库存、推广、关键词、竞品与每日操作使用统一数据接口。阿里云上线及跨电脑迁移请遵循 [数据迁移与回滚说明](docs/deployment/aliyun-data-migration.md)。数据库备份使用 `pnpm ops:backup`，校验使用 `pnpm ops:verify-backup`。

这是圣诞服经营驾驶舱。当前页面通过受保护的服务器接口保存业务、广告、库存和操作记录；同一个服务器的数据可跨电脑访问。旧版浏览器 IndexedDB（数据库名 `santa-ops`）中的历史数据需要通过“迁移本机数据”流程核对后迁移，本机预览库不会自动同步到云端。

## 首次启动

在项目目录运行 `pnpm install`，然后运行 `pnpm dev`，打开终端显示的 Local URL。首次启动不会展示演示经营值；KPI 使用破折号，并提示先导入报告。

### 本机免登录预览

构建后运行 `pnpm preview:local`，打开 `http://127.0.0.1:3011/`。这个入口使用 `.wrangler/manual-entry-preview` 中的独立预览库，只监听 `127.0.0.1`，无需输入访问密码；保存和修改数据仍需要原操作密码。页面会显示“本地免登录 · 保存仍需操作密码”，不会出现退出登录按钮。

免登录由服务器配置 `SANTA_OPS_LOCAL_PASSWORDLESS_ORIGIN` 显式启用，必须精确匹配本机规范 origin；默认 `dev` / `start` 不开启此设置，线上认证保持不变。`localhost` 与 `127.0.0.1` 不是同一个 origin，请使用上述网址。不要把此配置带入公网部署，也不要将免登录预览改为监听 `0.0.0.0` 或放在反向代理后。

它只自动创建普通访问会话，不创建操作会话，不重置密码或删除数据。关闭开关只停止自动创建会话，既有访问会话仍遵循原 14 天有效期；需要立即撤销时应走正常退出/会话撤销流程。

## 每日操作

首页“手动录入销量”支持日期、ASIN、SKU、销量、销售额、售价和折扣方式，选择 ASIN 或 SKU 会自动补齐另一项并关联尺码。售价是页面单价，销售额按实际成交总额填写（美元）；可以记录 0 销量、0 销售额。保存后刷新销量对比、销售额和均价统计。同一天同一商品已有业务记录时，必须勾选确认覆盖；原记录的流量、退款等其他字段保留。

首页或“广告推广”中的“手动录入广告”支持单日广告活动的展示量、点击量、总成本、购买量、销售额、搜索结果首页首位展示量份额和是否调整，ASIN / SKU 选填。CPC、点击率、转化率、ACOS 和 ROAS 自动计算，零分母或未统计的指标显示破折号。重复记录确认后覆盖，不叠加。同名“总成本”只作为一项花费保存。

“导入今日数据”和“广告推广 → 上传广告报表”支持明确选择报告类型。广告导出兼容“广告活动名称 / Campaign Name”“总成本 / Cost / Spend”“购买量 / Purchases / Orders”以及归因销售额等列名，中文 UTF-8 CSV 无需 BOM。单日导出缺少日期列时，手动填写“广告报表日期”；系统不会把广告活动开始日期当作报表日期。多日汇总应重新导出按日报表；缺失的广告销售额或购买量须补齐后保存，不自动填 0。

1. 点击“导入今日数据”，选择业务报告或广告报告（CSV/XLSX/XLS）。系统优先按报告列名识别类型；只有列名不足以识别时，才用文件名中的 `ad`、`ads` 或 `advertising` 作为辅助提示。
2. 查看有效行、问题行和重复记录预览。发现重复键时必须明确选择“忽略重复”或“替换旧记录”，再保存。
3. 在“手工记录”中填写日期、尺码、入库、库存调整、事件、问题、动作和完成状态。促销、Deal、调价等事件会出现在销售趋势图参考线上。没有观测到入库或库存调整时请留空；留空会保持为未知，不会自动变成零。
4. 使用日期、尺码（全部/L/XL/2XL/3XL）和每日/每周/累计筛选。每周按 ISO 周一开始；累计均价、ACOS 和毛利率按累计分子/分母重算。

刷新或重新打开页面会从服务器重新载入数据。删除浏览器 IndexedDB 不会清空服务器数据；迁移确认前不要删除旧版浏览器中的历史数据。

每次正式导入会在同一个本地事务中保存：原始文件字节（`rawImports`）、逐行原始值（`rawRows`）、标准化结果审计副本（`derivedResults`）、正式业务/广告记录和带引用键的导入日志（`imports`）。因此可以从导入日志追溯到原始证据和当时生成的标准化结果。

- [`public/sample-ad-report.csv`](public/sample-ad-report.csv)：广告花费 US$800，广告销售额 US$4,000，ACOS 20%，覆盖四个尺码主 ASIN。

## 数据质量说明

### 关键词搜索量与广告看板

关键词入口：经营模块导航 → 关键词排名 → 搜索量趋势。真实搜索量取自 Seller Central 的 Brands → Brand Analytics → Search Analytics → Search Query Performance（搜索查询绩效），不是 Top Search Terms 的 ABA 搜索频率排名。官方口径见 [Amazon Brand Analytics](https://sell.amazon.com/blog/brand-analytics)。本次功能通过上传数据使用真实次数，不自动连接 Amazon 账号。

搜索量默认按天展示，可多选关键词、选择 ASIN 和日期范围。日数据模板包含“关键词、ASIN、统计周期、日期、搜索量、统计范围、来源”，统计周期填写 `day`，每天必须是真实单日记录；也兼容相同的开始/结束日期。日变化只比较前一个自然日，缺少昨天的数据时显示未知，不使用最近一次记录代替。

原报告的周、月、季度数据仍可切换查看并保留完整区间，不拆分或平均成每日搜索量。ABA 排名与搜索次数分开存储，搜索量导入不会覆盖已有排名。不同 ASIN 报告里重复出现的同一市场关键词搜索量不累加；相同区间数值冲突、缺少上期或上期为零会明确提示，不生成误导性百分比。

广告入口：经营模块导航 → 广告数据看板。日期、活动、ASIN 和 SKU 筛选统一作用于指标、趋势和异常；“只看异常”仅筛选明细，不改变整体统计口径。看板内有广告报告导入和手动录入入口。ACOS、CTR、CPC、广告转化率和无订单花费的阈值可调整，近期广告归因可能尚未完成，异常提示用于复查，不自动修改广告投放。

比率按原始分子、分母重算，不平均各行百分比。分母为零或流量字段未完整录入时显示未知，并披露已知数据覆盖。疑似活动汇总/商品明细重叠、商品映射冲突等记录保留原样，提示复核并从可信汇总中排除；没有自动合并或删除历史记录。

发布源码与迁移业务数据是两个独立步骤。GitHub 不应包含数据库、原始工作簿、密码或部署密钥；云端数据同步应先备份，再核对同键冲突并按记录合并，不能用本地库整体覆盖云端库。

## 本地验证

运行 `pnpm vitest run --exclude tests/rendered-html.test.mjs`、`pnpm typecheck`、`pnpm lint`、`pnpm plan:check` 和 `pnpm test`。`pnpm test` 已包含生产构建和独立 HTML 渲染测试；项目不包含部署步骤。

## GitHub 与服务器部署说明

本仓库可以托管在 GitHub，用于保存源码、版本记录和后续服务器部署。当前项目是 Vinext/React 应用，生产运行方式是先构建再启动 Node 服务：

```bash
pnpm install
pnpm build
PORT=3010 pnpm start
```

本项目不建议直接使用 GitHub Pages 作为最终运营环境：GitHub Pages 只适合纯静态页面，而当前应用包含 Vinext 服务端运行产物。若只是保存代码，请直接推送到 GitHub；若要在其它电脑通过网址访问，请部署到阿里云 ECS、Vercel、Netlify 或其它可运行 Node 服务的平台。

重要：服务器数据默认保存于 `data/santa-ops.sqlite`，也可通过 `SANTA_OPS_DB_PATH` 指定。更新代码时必须保留现有数据库和生产启动配置；不要将本地免登录配置带入公网部署。本机预览库与云端库独立，只有经过备份和冲突核对的数据合并才算完成同步。

## 第二版：计划与库存

驾驶舱右上角的“计划与库存”会打开独立的经营管理页；原有仪表盘、KPI 顺序和四张折线图保持不变。首次进入时，系统会把第一版保存的周计划权重转换为 ISO 周一开始的日计划：原始周计划的周总量不会改变，尺码按采购数量权重以确定性的最大余数法分配。此初始化计划保存到本机 IndexedDB，之后以保存后的日计划作为驾驶舱计划销量和完成率的来源。

在“日度计划”中可直接调整日期和 L、XL、2XL、3XL 销量。计划总量 2900–3100 件（含边界）显示绿色并允许保存；2899 或 3101 等范围外计划显示红色且无法保存。保存时必须填写调整原因，系统保留当前有效计划及最近一次调整信息。

“导入库存报告”支持 CSV、XLSX、XLS，可识别 Amazon 的 SKU/ASIN 与 FBA 可售库存；未映射标识只会进入问题清单。每个尺码可维护在途数量和预计到仓日期；留空即表示未知，不会当作 0。

风险区要求近 7 个连续自然日销量，以及完整的可售、预留、不可售、在途和剩余计划数据。季末积压率超过 15% 且不超过 25% 为黄色，超过 25% 或预计到仓晚于预计售罄日为红色；缺失数据明确显示“数据不足”。四个尺码独立展示，任一红色风险会保留在汇总中。
