# 2026 圣诞服每日经营驾驶舱设计说明

## 1. 目标

为美国亚马逊 2026 年 3000 件圣诞服项目建立一个本地交互式经营网站，供操盘手每天更新数据、识别计划差异、监控利润与广告效率、预判断货和积压风险，并快速截图汇报。

网站只读取源工作簿与用户导入的报告，不修改源文件。现有工作簿中的「目标&假设」「利润规划表」「2026采购-fba到货周期」是计划、售价、成本和备货结构的基准。

## 2. 交付形态

- 本地运行的单页交互式网站，数据默认保存在当前设备。
- 支持导入亚马逊业务报告和广告报告。
- 支持手填库存修正、在途变化、促销/Deal/调价事件、异常原因、当天动作及完成状态。
- 首期不包含登录、云数据库和多人协作。

## 3. 首页设计

保留已确认的第一版展示结构，不改变图表布局：

1. 顶部：数据截止日期、日期筛选、尺码筛选、导入今日数据。
2. KPI 卡片：销量完成率、销售额、均价、毛利润/毛利率、广告花费/ACOS。
3. 主分析区：计划销量与实际销量对比；支持每日与累计切换。
4. 风险区：各尺码库存、预计售罄日、旺季结束预计剩余库存和积压风险。
5. 趋势区：销售额/均价、毛利润/毛利率、广告花费/ACOS 折线图。
6. 行动区：今日异常、建议动作及完成状态。

折线图必须保留。调价、优惠券、Deal、站外推广等事件以时间标记叠加在趋势图上。

## 4. 颜色规则

- 绿色：完成、达到或超过目标、风险已处理。
- 红色：未完成、低于目标、超过风险阈值、需要立即处理。
- 黄色：接近阈值或趋势恶化，但尚未触发正式风险。

颜色只表达经营状态，不作为装饰色。所有状态同时显示文字标签，避免仅依赖颜色传达信息。

## 5. 指标口径

- 销量完成率 = 实际销量 / 计划销量。
- 销量差异 = 实际销量 - 计划销量。
- 销售额 = 实际订单销售额。
- 销售额差异 = 实际销售额 - 计划销售额。
- 均价 = 销售额 / 实际销量；销量为零时显示为空，不计算为零售价。
- 毛利润 = 销售额 - 采购成本 - 头程 - FBA 费用 - 亚马逊佣金 - 广告花费 - 促销折扣 - 退款损失。
- 毛利率 = 毛利润 / 销售额；销售额为零时显示为空。
- ACOS = 广告花费 / 广告销售额；广告销售额为零时显示为空并提示风险。
- 可售库存 = FBA 可售 + 在途 - 预留/不可售库存。
- 预计售罄日 = 当前库存 / 近 7 日平均销量；近 7 日无销量时标记为滞销风险。
- 旺季结束预计剩余库存 = 当前可售库存 + 旺季内预计到仓量 - 旺季剩余日期预测销量。
- 积压率 = 旺季结束预计剩余库存 / 当前可售及旺季内在途库存。

所有指标支持按日、周、累计和尺码查看。计划差异同时显示件数、金额和完成率。

## 6. 数据导入与处理

### 亚马逊业务报告

必要字段包括日期、ASIN/SKU、销量、销售额。若报告提供退款、FBA 可售、预留和不可售库存，则同时导入；缺少的库存字段由手填记录补足。

### 广告报告

必要字段包括日期、广告活动、花费、广告销售额、广告订单。点击、曝光、CPC、CTR 和 CVR 在报告提供时导入，首版不将它们设为首页强制指标。

### 处理流程

1. 识别报告类型与列名。
2. 标准化日期、金额、百分比、SKU 和 ASIN。
3. 使用工作簿中的映射识别 L、XL、2XL、3XL。
4. 按日期与业务主键去重；重复导入同一记录时先提示，再允许替换。
5. 关联计划、成本与目标参数。
6. 计算日、周、累计和尺码指标。
7. 更新图表、风险状态和行动清单。

原始导入记录保留为数据源，清洗和计算结果独立存放，保证可追溯。

## 7. 默认风险规则

阈值优先读取「目标&假设」。工作簿没有明确设置时使用以下可编辑默认值：

- 销量完成率低于 90%：红色。
- ACOS 高于目标：红色。
- 毛利率低于目标：红色。
- 预计在旺季结束前断货：红色。
- 旺季结束预计积压率超过 15%：黄色；超过 25%：红色。
- 核心指标连续三天恶化：加入异常清单。

风险计算按尺码分别执行，项目总计风险不覆盖尺码级异常。

## 8. 异常处理

- 缺少必要列：阻止该文件导入，并指出缺少字段。
- 日期或金额无法识别：列出问题行，允许用户修正后重新导入。
- SKU/ASIN 无法映射：进入待映射清单，不计入正式汇总。
- 重复记录：显示原记录和新记录，由用户选择忽略或替换。
- 销量、销售额或广告数据出现明显异常：标记但不自动删除。
- 部分数据尚未到齐：显示数据完整度和最后更新时间，避免把缺失值当成零。

## 9. 验证标准

- 计划总量与工作簿中的 3000 件一致，L、XL、2XL、3XL 四个尺码均能识别。
- 销量、销售额、广告花费和广告销售额可与导入报告汇总对账。
- 毛利润与毛利率能追溯到成本、费用和退款组成。
- 按日、周、累计和尺码筛选时，KPI 与折线图同步变化。
- 绿色、红色和黄色状态与阈值一致，并显示相应文字。
- 重复导入不会无提示地重复累计。
- 缺失值、零销量、零广告销售额等边界情况不会产生错误数字。
- 首页在常见桌面宽度下无需横向滚动，截图可用于日报或周报。

## 10. 明确不在首期范围内

- 在线账号与权限管理。
- 云端数据库和多人实时协作。
- 自动登录亚马逊后台抓取数据。
- 自动修改广告活动、价格或库存。
- 替代现有工作簿作为历史资料与计划依据。
