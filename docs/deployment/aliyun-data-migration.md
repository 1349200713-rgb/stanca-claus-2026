# 阿里云数据迁移与回滚

1. 暂停人工录入，记录当前代码版本和各资源数量。
2. 设置 `SANTA_OPS_DB_PATH`、`SANTA_OPS_BACKUP_DIR`，运行 `pnpm ops:backup` 和 `pnpm ops:verify-backup`。
3. 新版本先部署到独立测试端口，不切换现有入口。
4. 配置服务端认证，确认未登录写请求被拒绝、已登录请求成功。
5. 在一台浏览器预览本机数据，核对数量与冲突后复制到云端；不删除 IndexedDB。
6. 核对业务、广告、库存、在途、推广、关键词、竞品和每日操作数量，并从第二台电脑确认一致。
7. 检查缺失值、未收录排名、原折线图和新漏斗图，再切换生产流量。
8. 每日运行 `pnpm ops:backup`，至少保留 30 天。

回滚时先停止服务，运行 `pnpm ops:restore -- -BackupPath <已验证备份> -ServiceStopped`，再部署上一代码版本。恢复脚本会先生成恢复前备份，任何校验失败都会拒绝覆盖。
